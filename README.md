# Task-4-Context-Aware-Chatbot
📌 Overview

This task demonstrates a context-aware chatbot that answers user queries based on a predefined knowledge base.

📂 Files

task4_Context_Aware_Chatbot.ipynb – Notebook implementing the chatbot logic

kb.txt – Knowledge base used by the chatbot

🧠 Objective

To build a simple chatbot that:

Reads information from a knowledge base

Matches user queries to relevant context

Returns appropriate responses

📚 Knowledge Base Topics

Refund policy

Account management

Technical support

Features updates

Billing information

⚙️ Technologies Used

Python

NLP basics (string matching / logic-based retrieval)

▶️ How to Run

Open task4_Context_Aware_Chatbot.ipynb

Ensure kb.txt is present in the same folder

Run the notebook cells

Interact with the chatbot via input prompts

💬 Example Use Case

User asks about refunds → chatbot responds using refund policy from kb.txt
